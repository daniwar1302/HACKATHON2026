# Unitree G1 + Dex1-1 model

`g1_29dof_mode_15_with_dex1_1.urdf` and the meshes it references (only those) are Unitree Robotics' G1 robot
description, copied from the robot's own software install (the `g1_description` package; Unitree's README is kept
as `README_unitree.md`). They belong to Unitree Robotics and are included here so waldo-sim runs without access to
the robot; check Unitree's published license for the package (unitreerobotics on GitHub) before reusing them
elsewhere.
